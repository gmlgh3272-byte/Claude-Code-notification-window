[도면내역검토 프로젝트 시작하기]

1. 처음 한 번
   - Python 설치 (python.org, 설치 첫 화면에서 "Add python.exe to PATH" 체크)
   - ODA File Converter 설치 (opendesign.com, 무료) - DWG 변환용
   - 이 폴더를 D:\도면내역검토 같은 곳에 두기

2. Claude 데스크톱 앱 > Code 탭 > 작업 폴더로 이 폴더 선택 (로컬)
   - 처음에는 "초기 설정해줘" 입력 (ezdxf, openpyxl 설치)

3. 학교 추가
   - 학교별\_새학교양식 폴더를 복사해서 학교명으로 이름 변경 (예: 학교별\신화중)
   - 도면 폴더에 DWG, 내역서 폴더에 엑셀 넣기

4. 검토
   - "신화중 내역 검토해줘" 또는 "/boq-review 신화중" 입력
   - 결과: 학교별\신화중\검토결과 폴더의 엑셀

5. 정확도 올리기
   - 결과에 "미매핑" 항목이 나오면 Claude가 매핑표 추가안을 제안함. 확인 후 승인
   - 검토 기준이 생기면 "앞으로 이건 이렇게 봐"라고 말하면 CLAUDE.md에 기록됨
