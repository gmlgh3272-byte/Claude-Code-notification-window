# 도면-내역 대조 검토

인자: 학교명 (`학교별/<학교명>` 폴더). 없으면 `학교별` 하위 폴더 목록을 보여주고 물어볼 것.

## 순서
1. **폴더 확인**: `학교별/<학교명>/도면`, `내역서` 파일 목록 확인. 비어 있으면 중단하고 알림.
2. **도면 변환·분석** (dwg-reader 스킬 스크립트 사용, 도면 파일마다):
   ```
   python .claude/skills/dwg-reader/scripts/convert_dwg.py "학교별/<학교명>/도면" --out "학교별/<학교명>/검토결과/dxf"
   python .claude/skills/dwg-reader/scripts/analyze_dxf.py "<도면.dxf>" --xlsx "학교별/<학교명>/검토결과/<도면명>_도면분석.xlsx" --json-out "학교별/<학교명>/검토결과/<도면명>_도면.json"
   ```
   도면 폴더에 DXF가 이미 있으면 변환 생략하고 바로 분석.
3. **내역서 읽기**:
   ```
   python .claude/skills/boq-review/scripts/read_boq.py "학교별/<학교명>/내역서" --out "학교별/<학교명>/검토결과/내역.json"
   ```
   `sheets_used`, `sheets_skipped`를 확인해서 엉뚱한 시트가 포함/제외됐으면 `--sheets`로 다시 실행.
4. **대조**:
   ```
   python .claude/skills/boq-review/scripts/compare.py --drawing "학교별/<학교명>/검토결과/"*_도면.json --boq "학교별/<학교명>/검토결과/내역.json" --map "공통/품목매핑.csv" --out "학교별/<학교명>/검토결과/<학교명>_내역대조_<YYYYMMDD>.xlsx"
   ```
5. **매핑 보완**: 미매핑 블록·미매핑 내역 중 전기·통신·소방 기구로 보이는 것은 `공통/품목매핑.csv`에 추가할 행을 제안. 사용자 승인 후에만 수정하고 4번 재실행.
6. **보고**: CLAUDE.md의 보고 형식을 따름.

## 판정 해석
- 개수 항목: 일치 / 수량 불일치 / 도면에만 있음 / 내역에만 있음
- 길이 항목: 내역÷도면 비율이 허용범위(기본 1.0~1.5) 안이면 참고, 밖이면 확인 필요. 할증·입상·여장이 반영 안 된 값이므로 확정 판단 금지.
