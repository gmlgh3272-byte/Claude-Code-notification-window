# 도면·내역 검토 프로젝트

## 나(사용자)와 업무
- 서울특별시교육청 강서양천교육지원청 전기직 공무원. 학교 전기·통신·소방 설계 검토와 공사 감독 담당, 동시 30개교 이상 관리.
- 이 폴더의 목적: 설계도면과 엑셀 내역서를 대조해서 수량 불일치, 누락, 규격 상이를 찾아내는 것.

## 폴더 규칙
- `학교별/<학교명>/도면`: DWG 또는 DXF
- `학교별/<학교명>/내역서`: 엑셀 내역서(.xlsx)
- `학교별/<학교명>/검토결과`: 모든 산출물 저장 위치. 원본 도면·내역서는 절대 수정하지 않음
- 새 학교는 `학교별/_새학교양식` 폴더를 복사해서 이름만 바꿔 사용
- `공통/품목매핑.csv`: 도면 블록·레이어와 내역 품명을 연결하는 규칙. 학교를 거치며 계속 보완

## 검토 방법
- 내역 검토 요청이 오면 `boq-review` 스킬 절차를 따름
- 도면만 볼 때는 `dwg-reader` 스킬 사용

## 보고 형식
비서가 먼저 서류를 보고 보고하는 방식. 반말, 핵심부터.
1. 결론: 확인이 필요한 항목 수와 가장 중요한 것 3개
2. 수량 불일치 표: 품목 / 도면 / 내역 / 차이 / 근거(시트·행)
3. 누락 의심: 도면에만 있음, 내역에만 있음
4. 미매핑 항목: 매핑표에 추가할 행 제안
5. 한계 고지: 길이 물량은 참고치, xref·선으로 그린 기구 미집계 등
6. 3줄 요약

## 검토 기준 (사용자가 알려주는 대로 계속 추가)
- 길이 항목 허용비율 기본값: 내역/도면 1.0~1.5
- (예시) 소방 감지기는 도면 수량과 정확히 일치해야 함

## 주의
- 도면과 내역서는 이 PC에만 둠. 깃허브 등 외부 업로드 금지
- 수정은 매핑표·CLAUDE.md만, 그것도 사용자 승인 후에만
